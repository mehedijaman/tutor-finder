# Plan: Make Entire VILT Frontend Fully Responsive

## Scope

145 Vue files across Admin (91), Tutor (13), Guardian (14), Auth (8), Settings (4), Public (15) panels. Only frontend files (Vue components, Tailwind classes, layouts). No backend changes.

## Current State Assessment

**Already responsive (keep as-is):**
- Sidebar: auto-collapses to Sheet on mobile via shadcn-vue primitives (768px)
- DataTable: has mobile card view (`hidden sm:block` table, `sm:hidden` cards)
- Dashboard grids: `sm:grid-cols-2 lg:grid-cols-3/4 xl:grid-cols-4/5`
- Page padding: mostly `p-4 sm:p-6 lg:p-8`
- StatCard/ActionCard: responsive typography
- FilterBar: stacks on mobile
- PageHeading: responsive layout
- Settings layout: responsive sidebar

**Issues to fix:**
1. Inconsistent page container patterns (some `p-6 lg:p-8`, some `p-4 sm:p-6`)
2. Page headers missing responsive scaling (`text-3xl` without `sm:`)
3. Filter bars with fixed `min-w-[240px]` causing overflow on small screens
4. Select triggers with fixed widths (`w-[160px]`, `w-[180px]`)
5. Some form sections inconsistent grid breakpoints
6. Detail pages with rigid layouts
7. Dialogs/sheets need mobile content scroll verification
8. DataTable needs column visibility and improved mobile cards

---

## Phase 1: Shared Responsive Infrastructure

Create reusable components to standardize patterns across all pages.

### 1.1 Create `PageContainer.vue`
**Path:** `resources/js/components/PageContainer.vue`

Wraps page content with consistent padding and max-width:
```html
<div class="mx-auto w-full max-w-7xl space-y-6 p-4 sm:p-6 lg:p-8">
  <slot />
</div>
```

### 1.2 Create `PageHeader.vue` (unified)
**Path:** `resources/js/components/PageHeader.vue`

Replace both `admin/PageHeader.vue` and `PageHeading.vue` with a single responsive component:
- Title: `text-2xl sm:text-3xl`
- Description: `text-sm sm:text-base`
- Layout: `flex flex-col gap-4 sm:flex-row sm:items-center sm:justify-between`
- Icon + title alignment works on mobile

### 1.3 Create `ResponsiveGrid.vue`
**Path:** `resources/js/components/ResponsiveGrid.vue`

Standard grid patterns:
- `stats`: `grid gap-4 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4`
- `actions`: `grid gap-4 sm:grid-cols-2 lg:grid-cols-3`
- `form`: `grid gap-4 sm:grid-cols-2`
- `detail`: `grid gap-6 xl:grid-cols-[320px_minmax(0,1fr)]`

### 1.4 Create `ResponsiveFilterBar.vue`
**Path:** `resources/js/components/ResponsiveFilterBar.vue`

Standard filter bar that:
- Stacks vertically on mobile
- Wraps on tablet
- Horizontal on desktop
- No fixed `min-w` values - uses `w-full sm:w-auto`
- Select triggers: `w-full sm:w-auto` instead of fixed widths
